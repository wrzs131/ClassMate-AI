## 二、填空题

### 11. 【解】
∵ 单项式 $3a^m b^2$ 与 $-\dfrac{2}{3}a^4 b^{n-1}$ 的和仍为单项式，  
∴ $3a^m b^2$ 与 $-\dfrac{2}{3}a^4 b^{n-1}$ 是同类项，  
∴ $m = 4$，$n - 1 = 2$，  
解得 $m = 4$，$n = 3$，  
∴ $m + 2n = 4 + 2 \times 3 = 10$。  
故答案为：10。

### 12. 【解】
∵ $\left| -\dfrac{1}{3} \right| = \dfrac{1}{3}$，$\left| -\dfrac{1}{4} \right| = \dfrac{1}{4}$，  
又∵ $\dfrac{1}{3} > \dfrac{1}{4}$，  
∴ $\left| -\dfrac{1}{3} \right| > \left| -\dfrac{1}{4} \right|$，  
∴ $-\dfrac{1}{3} < -\dfrac{1}{4}$。  
故答案为：$<$。

### 13. 【解】
列出 $-4$，$-2$，$0$，$1$，$3$ 中任取两个数相乘的所有结果：  
$(-4) \times (-2) = 8$；$(-4) \times 0 = 0$；$(-4) \times 1 = -4$；$(-4) \times 3 = -12$；  
$(-2) \times 0 = 0$；$(-2) \times 1 = -2$；$(-2) \times 3 = -6$；  
$0 \times 1 = 0$；$0 \times 3 = 0$；$1 \times 3 = 3$。  
比较所有结果大小：$-12 < -6 < -4 < -2 < 0 < 3 < 8$，  
故最大的积 $a = 8$，最小的积 $b = -12$，  
则 $ab = 8 \times (-12) = -96$。  
故答案为：$-96$。

### 14. 【解】
∵ $|x| = 3$，$|y| = 2$，  
∴ $x = \pm 3$，$y = \pm 2$，  
又∵ $x < y$，  
∴ $x = -3$，$y = 2$ 或 $x = -3$，$y = -2$，  
当 $x = -3$，$y = 2$ 时，$x + y = -3 + 2 = -1$；  
当 $x = -3$，$y = -2$ 时，$x + y = -3 + (-2) = -5$。  
故答案为：$-1$ 或 $-5$。

### 15. 【解】
∵ $|x - 3| + (y - 2)^2 = 0$，$|x - 3| \ge 0$，$(y - 2)^2 \ge 0$，  
∴ $|x - 3| = (y - 2)^2 = 0$，  
∴ $x - 3 = 0$，$y - 2 = 0$，  
∴ $x = 3$，$y = 2$，  
∴ $y^x = 2^3 = 8$。  
故答案为：8。
