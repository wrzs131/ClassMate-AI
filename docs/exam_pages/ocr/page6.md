16.【解】解：根据数轴得出 $b < a < 0 < c < 1$，且 $|a| < |c|$，  
$\therefore a + b < 0, b - 1 < 0, a + c > 0$  
则 $|a + b| - |b - 1| + |a + c|$  
$= -a - b - (1 - b) + a + c$  
$= -a - b - 1 + b + a + c$  
$= -1 + c$，  
故答案为：$-1 + c$．
