   C. $632.4 \times 10^9$

4. 有理数 $a$，$b$ 在数轴镇上的位置如图所示，下列各式成立的是（ ）

9. 定义：$a$ 是不为1的有理数，我们把 $\dfrac{1}{1 - a}$ 称为 $a$ 的差倒数。如：2的差倒数是 $\dfrac{1}{1 - 2} = -1$，-1的差倒数是 $\dfrac{1}{1 - (-1)} = \dfrac{1}{2}$。已知 $a_1 = 2$，$a_2$ 是 $a_1$ 的差倒数，$a_3$ 是 $a_2$ 的差倒数，$a_4$ 是 $a_3$ 的差倒数，…，以此类推，则 $a_{2025}$ 的值是（ ）  
   A. 2  
   B. -1  
   C. $\dfrac{1}{2}$  
   D. 不能确定
